# Object-Oriented Software Project Management System

A Python-based project management system developed as part of an 
Object-Oriented Programming course at Konkuk University, Seoul.

## Features
- Developer and task management
- Task status tracking (Pending/In Progress/Completed)
- Project progress overview
- Demonstrates OOP concepts: Encapsulation, Inheritance, Polymorphism, Composition

## Usage
Run `python3 main.py` and follow the CLI menu.
